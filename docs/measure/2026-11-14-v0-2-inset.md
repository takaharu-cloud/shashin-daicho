# v0.2 の余白を 2 つの画面の拡大率で測って決める（2026-11-14）

写真の枠の内側の余白を詰めて、写真を今より大きく置く。そのための余白を、本物の Excel が出す PDF で測って決めた。測った絵は、架空の絵（4:3・16:9・3:4）だけ。

## 採る値
`inset = { leftPx: 5, topPx: 5, rightPx: 5, bottomPx: 12 }`

4:3 の絵は 105.13×78.85mm（v0.1 の 102.66×76.99mm より、幅で約 2.4%・高さで約 2.4% 大きい）。

| 環境 | 4:3 の 4 辺のすき間 左, 右, 上, 下（mm） | 16:9（幅いっぱい）の左, 右（mm） |
|---|---|---|
| 120dpi（今日のふつうの Excel）・測った | 2.87, 5.25, 1.20, 5.37 | 1.20, 3.57 |
| 96dpi（昨日の刷り）・計算 | 2.87, 5.25, 約 1.07, 約 1.81 | 1.20, 3.57 |

- 96dpi 側の上と下は、測りでなく計算（下の「分かった事」の 3）。昨日の `PAD=12` の測り（上 2.96・下 1.77mm）と、今日の同じ台帳の測り（上 3.09・下 5.33mm）の差を、上は -0.13mm、下は枠の高さの差（81.73mm と 85.41mm）で引き直した。
- 選んだ線は、2 つの環境の両方で、上と左のすき間が 1.0mm 以上・下と右が 1.5mm 以上・縦横比のずれが 1% 以内・4 つの値が 4px 以上。その中で 4:3 の絵が一番大きい組。
- 上と左は 5px 未満だと 1.0mm を割る（4px で上 0.93mm）。下は 12px を変えなかった（昨日の 96dpi で測った唯一の値。11px にすると 96dpi の下が約 1.55mm になり、計算の誤差の中に入る）。

## 分かった事
1. 出力先のプリンタを替えても、枠・行・列の大きさは変わらなかった（4 台：仮想 PDF・仮想 XPS・複合機・インクジェット）。専用の Excel の中だけで切り替え、Windows の既定のプリンタは前後で変えていない。
2. 変わるのは、Excel を動かす PC の画面の拡大率。行の高さの刻みが、96dpi では 0.75pt、今日の画面では 0.6pt になり、刷りで行が伸び縮みする割合が違う。
   | | 列の幅 | 行の高さ | 枠（印刷）mm |
   |---|---|---|---|
   | 設計（420×315px） | | | 111.13×83.34 |
   | 96dpi（昨日） | +1.9% | -1.9% | 113.25×81.73 |
   | 120dpi 相当（今日） | +1.9% | +2.5% | 113.25×85.41 |
   絵は EMU の大きさのまま刷られ、枠だけが伸び縮みするので、上下のすき間が動く（下で 約 3.6mm）。
3. 96dpi の環境を設定を変えずに再現する試み（Excel を DPI を知らない形の別プロセスで起こす）は、2 通り（`DPIUNAWARE`・`GDIDPISCALING DPIUNAWARE`）とも効かず、行の高さは 7.5pt の指定が 7.2pt のままだった。このため 96dpi 側は計算。
4. 右のすき間は左より約 2.3mm 広い。列が +1.9% 広がるのに、絵は広がらないため。

## 1 ページ 3 枚の余り（`PAD=12`・N=7・1 ページ目）
| 環境 | 3 段目の枠の下端（紙の上から） | 下の余白（282mm）までの余り | ページ数・各ページの絵 |
|---|---|---|---|
| 96dpi（昨日） | 265.83mm | 16.17mm | 3 ページ・3, 3, 1 |
| 120dpi（今日） | 277.14mm | 4.86mm | 3 ページ・3, 3, 1 |

120dpi でも 3 段は 1 ページに入る。ただし余りは 4.9mm しかなく、拡大率がもっと高い画面（測っていない）では 3 段目が次のページへ送られうる。

## 2 ページに割れた出力先
複合機（1 回の出力に 107 秒かかった物）は、紙が A4 でなく Letter（215.9×279.4mm）の PDF になり、3 段目が次のページへ割れた。行の伸びではなく紙の大きさの違いが訳。行と列の伸び縮みは、ほかの 4 台と同じ（+1.9%・+2.5%）。

## 目で見た結果
採った組（120dpi）の PDF を絵にして、4:3・16:9・3:4 とも見た。絵は枠の線に乗っておらず、見出しと値の字は欠けていない。96dpi 側の絵は、採った組では作れなかった（再現できないため）。

## 測っていない事
- 拡大率 150% 以上の画面・Mac の Excel・ほかの版の Excel・LibreOffice・紙への本当の印刷。
- 96dpi 側の上と下のすき間は計算（誤差 約 ±0.1mm の見込み）。
- 出力先のプリンタは 4 台（1 台は切り替え失敗・1 台は紙の大きさが違う物）。
