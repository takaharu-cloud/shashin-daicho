# 写真台帳 v0.2（余白を詰める・右の欄を選ぶ）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 台帳の写真を切らずに大きく置き、右の欄を保存の前にチェックで選べるようにし、よくある質問の 2 文を直す。

**Architecture:** 1 段の行の数（8 行＋すき間 1 行）は変えない。選んだ欄を上から詰め、最後の欄（備考か空き）を残りの行に縦につないで広げる。だから行番号・印刷範囲・改ページは v0.1 のまま動く。余白は 1 つの数（`padPx`）から、左・上・右・下の 4 つ（`inset`）に替える。

**Tech Stack:** ブラウザの ES モジュール（`src/*.js`）・ExcelJS 4.4.0（`vendor/`・変えない）・`node --test`・Python 3（`tools/inspect_xlsx.py`＝Excel の COM と PyMuPDF）。

**Spec:** `docs/superpowers/specs/2026-11-14-v0-2-design.md`

## Global Constraints

- 元の写真は読むだけ。外への通信 0。`vendor/` は 1 バイトも変えない。`npm install`・`pip install`・ダウンロードを足さない。
- HP の CSP の下で動く。インラインのスクリプトとスタイル（`style=` を含む）を書かない。
- A4 縦・1 ページ 3 枚・1 冊 150 枚・いちどに 300 枚は変えない。列の幅 `colPx: [420, 8, 64, 166]` は変えない。
- 1 段の 8 行の高さの合計は、いつも 236.25pt。すき間の行は 7.5pt。
- 全部の欄を選んだ時（`fields` を渡さない時を含む）は、行の高さ・見出し・値・結合が v0.1 と同じ。
- 絵は切らない・ゆがめない（縦横比のずれ 1% 以内）。`br`・`editAs` を渡さない（oneCellAnchor のまま）。
- 欄のキー（この順）：`number`・`date`・`file`・`koushu`・`shubetsu`・`saibetsu`・`place`・`note`。見出しは順に「写真番号」「撮影年月日」「ファイル名」「工種」「種別」「細別」「撮影箇所」「備考」。
- 試す写真は `tools/make_fixtures.py` の架空の絵だけ。実名（人・会社・現場）を、コード・コメント・試験のデータ・コミット文に書かない。
- ファイルは LF。Python でリポのファイルを書く時は bytes。`test/no_cr.test.mjs` が緑。
- ページの文の表記：和字と英数字の間に空白を置かない。「こと」「とき」「できる」はひらがな。盛った言葉（簡単・すぐに・誰でも・楽に）を使わない。
- Excel は専用の物を見えない形で起こし（`DispatchEx`・`Visible=False`）、名前で強制終了しない。ブラウザやサーバを裏に残さない。
- コミット文の最後の行：`Co-Authored-By: Claude Fable 5.2 <noreply@anthropic.com>`

## Review Focus

1. `fields` に、知らないキー・重複・文字列でない物・配列でない物が来る。落ちずに、知らない物は捨て、配列でなければ全部として扱う。
2. 「ファイル名」を外した台帳に、16:9 や細長い絵（絵の上の位置が 2 行目より下になる）を置く。絵が枠の中に入り、枠の真ん中からずれない。
3. 欄を 0 個にして、1 枚だけの台帳と、4 枚（改ページ 1 回）の台帳を作る。印刷範囲とページ数が全部の時と同じ。
4. 冊が分かれる保存（151 枚以上）の途中でチェックを変える。1 回の保存の冊が、全部同じ形になる。
5. キーボードだけでチェックを変えられる。読み上げで、組の名前「台帳に入れる欄」が分かる。

### Task 2: `layout.js` — 余白 4 つと、選んだ欄から行の並びを作る

**Files:**
- Modify: `src/layout.js`
- Test: `test/layout.test.mjs`

**Interfaces:**
- Consumes: Task 1 の `inset` の 4 つの値（controller が発注文に書く）。
- Produces:
  - `SHEET.inset: { leftPx, topPx, rightPx, bottomPx }`。`SHEET.padPx` は消す。`SHEET.imageBox` は `{ wPx: 420 - leftPx - rightPx, hPx: 315 - topPx - bottomPx }`。
  - `SHEET.fields: [{ key, label, pt }]`（8 つ・Global Constraints の順。`pt` は 18・18・45・18・18・18・18・83.25）。`SHEET.labels`・`SHEET.rowPt` は残す（全部の時の並び）。
  - `export const FIELD_KEYS: string[]`（8 つ）
  - `export function normalizeFields(fields): string[]` — 配列でなければ全部。配列なら、`FIELD_KEYS` に有る文字列だけを、`FIELD_KEYS` の順で、重複なしで返す（空の配列は空のまま）。
  - `export function blockLayout(fields): { rowPt: number[], rows: { key: string, label: string, row: number, span: number }[] }`
  - `fitImage(w, h)` — 箱（枠−inset）に収め、箱の真ん中に置く。返す `x`・`y` は枠の左上から。
  - `imageAnchor(i, fit, rowPt = SHEET.rowPt)` — `rowPt` をたどって行を決める。

`blockLayout` の決まり（`sel = normalizeFields(fields)`・`body = sel から note を除いた物`・`m = body.length`）：
- `rowPt[k]`：`k < m` は `body[k]` の `pt`。`m <= k <= 6` は 18。`rowPt[7]` は `236.25 − (rowPt[0..6] の合計)`。
- `rows`：`body` を順に `{ key, label, row: k, span: 1 }`。最後に 1 つ足す。`note` が選ばれていれば `{ key: 'note', label: '備考', row: m, span: 8 - m }`、無ければ `{ key: 'blank', label: '', row: m, span: 8 - m }`。

  const a = blockLayout();
  assert.deepEqual(a.rowPt, [18, 18, 45, 18, 18, 18, 18, 83.25]);
  assert.deepEqual(a.rows.map((r) => [r.key, r.row, r.span]),

test('blockLayout：種別を外すと備考が 2 行ぶんになる', () => {

  assert.deepEqual(a.rowPt, [18, 18, 45, 18, 18, 18, 18, 83.25]);
  assert.deepEqual(a.rows.at(-1), { key: 'note', label: '備考', row: 6, span: 2 });

test('blockLayout：ファイル名を外すと最後の行が 110.25pt', () => {
  const a = blockLayout(FIELD_KEYS.filter((k) => k !== 'file'));
  assert.deepEqual(a.rowPt, [18, 18, 18, 18, 18, 18, 18, 110.25]);
  assert.deepEqual(a.rows.at(-1), { key: 'note', label: '備考', row: 6, span: 2 });
});
test('blockLayout：自動の 3 つだけは空きの行で埋める', () => {
  const a = blockLayout(['number', 'date', 'file']);
  assert.deepEqual(a.rowPt, [18, 18, 45, 18, 18, 18, 18, 83.25]);
  assert.deepEqual(a.rows.at(-1), { key: 'blank', label: '', row: 3, span: 5 });

test('blockLayout：0 個は空きの行 1 つ', () => {
  const a = blockLayout([]);
  assert.deepEqual(a.rowPt, [18, 18, 18, 18, 18, 18, 18, 110.25]);
  assert.deepEqual(a.rows, [{ key: 'blank', label: '', row: 0, span: 8 }]);

test('blockLayout：どの組でも合計は 236.25pt・行は 8 つ', () => {
  for (let bits = 0; bits < 256; bits++) {
    const f = FIELD_KEYS.filter((_, i) => bits & (1 << i));
    const a = blockLayout(f);
    assert.equal(a.rowPt.length, 8);
    assert.equal(a.rowPt.reduce((s, v) => s + v, 0), 236.25);
    assert.equal(a.rows.reduce((s, r) => s + r.span, 0), 8);
    assert.ok(a.rowPt.every((v) => (v / 0.75) % 1 === 0));
  }
});
test('normalizeFields：知らない物・重複・順・配列でない物', () => {
  assert.deepEqual(normalizeFields(undefined), FIELD_KEYS);
  assert.deepEqual(normalizeFields('number'), FIELD_KEYS);
  assert.deepEqual(normalizeFields(['note', 'x', 3, null, 'number', 'note']), ['number', 'note']);
  assert.deepEqual(normalizeFields([]), []);
});
test('imageAnchor：渡した行の高さをたどる', () => {
  const fit = { x: 10, y: 60, w: 100, h: 50 }; // 60px＝45pt
  assert.equal(imageAnchor(0, fit).nativeRow, 2);                          // 18+18 の次の行
  assert.equal(imageAnchor(0, fit, blockLayout(['number']).rowPt).nativeRow, 2);
  assert.equal(imageAnchor(0, { ...fit, y: 120 }).nativeRow, 3);            // 90pt＝18+18+45 を越えて 4 行目
  assert.equal(imageAnchor(0, { ...fit, y: 120 }, blockLayout([]).rowPt).nativeRow, 5); // 18×5＝90 を越えて 6 行目
});
test('fitImage：箱（枠−inset）の真ん中に置く', () => {
  const { inset, frame, imageBox } = SHEET;
  assert.equal(imageBox.wPx, frame.wPx - inset.leftPx - inset.rightPx);
  assert.equal(imageBox.hPx, frame.hPx - inset.topPx - inset.bottomPx);
  for (const [w, h] of [[4, 3], [16, 9], [3, 4], [1, 10], [10, 1]]) {
    const f = fitImage(w, h);
    assert.ok(Math.abs(f.w / f.h - w / h) < 1e-9);
    assert.ok(f.x >= inset.leftPx - 1e-9 && f.x + f.w <= frame.wPx - inset.rightPx + 1e-9);
    assert.ok(f.y >= inset.topPx - 1e-9 && f.y + f.h <= frame.hPx - inset.bottomPx + 1e-9);
    assert.ok(Math.abs((f.x - inset.leftPx) - (frame.wPx - inset.rightPx - f.x - f.w)) < 1e-9);
    assert.ok(Math.abs((f.y - inset.topPx) - (frame.hPx - inset.bottomPx - f.y - f.h)) < 1e-9);
  }
});

### Task 3: `ledger.js` と道具 — 選んだ欄で台帳を組み、Excel で検査する

**Files:**

- Modify: `tools/build_ledger.mjs`・`tools/inspect_xlsx.py`

**Interfaces:**
- Consumes: `blockLayout(fields)`・`imageAnchor(i, fit, rowPt)`・`normalizeFields`（Task 2）。
- Produces:
  - `buildLedger(ExcelJS, entries, { startNumber?, title?, now?, fields? })`。`fields` は欄のキーの配列（無ければ全部）。返す形は変えない。
  - `node tools/build_ledger.mjs <組> [--sort date|name] [--fields <キーをカンマで。0 個は none>] [--tag <名前>]`。`--tag` が有れば、出力の名前（xlsx と expect.json）の `<組>_<sort>` の後ろに `_<名前>` を付ける。`expect.json` に `"fields": [...]`（正規化した後の配列）を書く。`--fields` が無い時は書かない。
  - `tools/inspect_xlsx.py` は `expect.json` の `fields`（無ければ全部）から、行の高さ・見出しの位置・結合を出して比べる。

台帳の組み方（1 段ごと・`L = blockLayout(fields)`・`first` は段の頭の行）：
- 8 行とも、高さを `L.rowPt[k]` にし、C 列と D 列のセルに字体と罫線（`BOX`）を付け、A 列に罫線を付ける（v0.1 と同じ）。
- `L.rows` の 1 つごと：
  - `blank` 以外：C(first+row) に見出し、D(first+row) に値（`number`＝`startNumber + i`／`date`＝`formatDateJa(...)`／`file`＝`fitFileName(cleanText(name))`／ほかは値なし）。`span > 1` の時、C と D を別々に縦につなぐ（`mergeCells(first+row, 3, first+row+span-1, 3)` と 4 列目）。
  - `blank`：C(first+row) から D(first+7) までを 1 つにつなぐ。値なし。
  - 縦の位置：`note` と `blank` は `top`、ほかは `middle`。C は `distributed`、D は `left`・`wrapText`（v0.1 と同じ）。
- 絵：`imageAnchor(i, fit, L.rowPt)`。印刷範囲・改ページ・A 列の結合は変えない。

動き：
- 保存のボタンを押した時に、チェックの付いた `value` を配列にして `buildLedger` に渡す。
- 冊が 2 つ以上の時は、最初の冊を保存した時の配列を覚え、残りの冊にも同じ配列を使う。最初の冊を保存したら、全部の冊を保存し終えるか「最初からやり直す」まで、`#fields` を `disabled` にする（並び順の錠と同じ考え方。今ある錠の作りに合わせる）。
- 「最初からやり直す」で、全部オンに戻し、`disabled` を外す。新しい写真を読み直した時も同じ。
